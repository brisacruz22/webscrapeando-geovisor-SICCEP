# webscrapeando-geovisor-SICCEP
Webscrapeando la base de datos geográfica que está detrás del geovisor del Sistema de Ciudades y Centros Poblados (SICCEP), del Observatorio Urbano Nacional.

Hola! Soy Brisa, socióloga por la PUCP y asistente de investigación en GRADE. A raíz de la ejecución de un estudio sobre ciudades en el Perú, me enteré de que ya existen tipologías oficiales de ciudades, que además están graficadas en el GeoVisor SICCEP. Lo interesante de esta aproximación es que utiliza definiciones basadas en continuos poblados, en lugar de limitarse a definiciones administrativas (ej.: conjunto de distritos), que pueden omitir la complejidad de las dinámicas de expansión urbana.

Lamentablemente, no encontré una forma intuitiva de descargar las capas del geovisor, así que probé webscrapeando, y resultó más sencillo de lo que creí. El resultado es una base de datos con 564 casos que, además de las geometrías de cada continuo poblado, incluye variables como el total de población dentro del polígono al 2025.

Si buscan hacer una investigación que utilice definiciones oficiales de continuos urbanos (sean ciudades o villas), esta base de datos resulta bastante útil.
